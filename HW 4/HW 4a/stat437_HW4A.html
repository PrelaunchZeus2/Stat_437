Equation 4.12: \(p+k(X) = \frac{\pi_k\frac{1}{\sqrt{2\pi\sigma}}exp(-\frac{1}{2\sigma^2}(x-\mu_k)^2)}{\sum^{K}_{l=1} \pi_l \frac{1}{2\pi\sigma}exp(-\frac{1}{2\sigma^2}(x-\mu_l)^2)}\)

Start by taking the numerator of 4.12 because the class that maximizes \(p_k(x)\) is the class that maximizes the numerator: \(\pi_k * exp(-1\frac{1}{2\sigma^2}(x-\mu_k)^2)\)

Next take the log to simplify the exponential function: \(\pi_k * exp(-1\frac{1}{2\sigma^2}(x-\mu_k)^2) = log(\pi_k) - \frac{1}{2\sigma^2}(x-\mu_k)^2\)

Expand the quadratic term: \((x - \mu_k)^2 = x^2 - 2x\mu_k + \mu^2_k\)

Put together we have \(log(\pi_k) - \frac{1}{2\sigma^2}(x^2 - 2x\mu_k + \mu^2_k) = log(\pi_k) - \frac{x^2}{2\sigma^2}+\frac{x\mu_k}{\sigma^2}-\frac{\mu^2_k}{2\sigma^2}\)

The term \(\frac{x^2}{2\sigma^2}\) does not depend on k so it is a constant term that can be dropped. Doing so leaves us with: \(log(\pi_k) + \frac{x\mu_k}{\sigma^2}-\frac{\mu^2_k}{2\sigma^2}\) with some re-arrangement we get…:

Equation 4.13: \(\delta_k(x) = x * \frac{\mu_k}{\sigma^2} - \frac{\mu^2_k}{2\sigma^2} + log(\pi_k)\)

Exercise 3 of Section 4.7 of the Text, which starts with “This problem relates to the QDA model, in which the observations within each class are drawn from a normal distribution with a class specific mean vector and a class specific covariance matrix. We consider the simple case where p = 1; i.e. there is only one feature.” (Helpful information on how to prove this is contained in the lecture video on QDA and “LectureNotes5b_notes.pdf”.)

The density of an observation from the kth class drawn from a 1D normal distribution is

\(f_k(x) = \frac{1}{\sqrt{2\pi\sigma^2_k}}exp(-\frac{(x-\mu_k)^2}{2\sigma^2_k})\) each class has a prior probability of \(\pi_k\)

The Bayes classifier assigns x to the class that maximizes the product \(\pi_kf_k(x) = \pi_k * \frac{1}{\sqrt{2\pi\sigma^2_k}}exp(-\frac{(x-\mu_k)^2}{2\sigma^2_k})\)

taking the log to simplify the exp(): \(log(\pi_kf_k(x)) = log(\pi_k)-\frac{1}{2}log(2\pi\sigma^2_k)-\frac{(x-\mu_k)^2}{2\sigma^2_k}\)

\(log(2\pi)\) is a constant so it can be dropped since it doesn’t on k: \(log(pi_k) - \frac{1}{2}log(\sigma^2_k)-\frac{(x-\mu_k)^2}{2\sigma^2_k}\)

expand the squared term: \((x-\mu_k)^2 = x^2 - 2x\mu_k + \mu^2_k\) so now its this: \(log(\pi_k) - \frac{1}{2}log(\sigma^2_k) - \frac{1}{2\sigma^2_k}(x^2 - 2x\mu_k + \mu^2_k)\)

distribute: \(\delta_k(x) = log(\pi_k)-\frac{1}{2}log(\sigma^2_k)-\frac{x^2}{2\sigma^2_k}+\frac{x\mu_k}{\sigma^2_k}-\frac{\mu^2_k}{2\sigma^2_k}\)

When comparing between two classes to decide which gives the higher discriminant score, the decision rules says we should pick the class that maximizes \(\delta_k(x)\). The coefficient in front of the \(x^2\) term changes for the different classes and the decision boundary equations is obtained by setting the discriminant functions for two classes equal to each other: \(\delta_k(x)=\delta_l()x\)

This gives a quadratic equation because of the differing \(x^2\) coefficients making the decision surface quadratic. The discriminant functions involve quadratic terms, so the resulting bayes classifier under the QDA model is not linear. Hence the name Quadratic Discriminant Analysis.

6.3) Is it true that discriminant analysis will perform badly if the Gaussian assumption is violated? (Hint: for this question, you may also use the information provided by Figures 4.10 and 4.11 of the Text.) Let \(X=(X_1,\ldots,X_p)^P\), i.e., \(X_1\) up to \(X_p\) are the feature variables. Can discriminant analysis be applied to observations of \(X\) when some of \(X_j,j=1\ldots,p\) is a discrete variable (such as a categorical variable)? Explain your answer.

When the Gaussian assumption is violated, there is not a guarantee that the discriminant model will perform poorly, however it is pretty likely that it will. The model will likely struggle to capture the true distribution of the data leading to incorrect classification boundaries. Especially the LDA model as it is more rigid in its assumption that the covariance matrices are the same across classes.

Discriminant Analysis cannot directly handle categorical features. The data it takes in needs to be continuous because the decision boundary is derived by calculating the likelihood of a data point belonging to a particular class. The categorical likelihood would be estimated by counting the frequency of each category so it doesn’t fit well with the Gaussian assumption.

6.4) What is a ROC curve, and what is AUC? How is AUC used to gauge the performance of a classifier? If you apply the same classifier, say, LDA or QDA under the same Gaussian mixture model, to two data sets that are independently generated from the same data generating process, i.e., that are independently generated from \((X,Y)\) for classification problems, and obtain two ROC curves, would the two ROC curves be quite different? Explain your answer. When there are 3 or more classes, are the codes provided in the lecture notes able to obtain ROC curves and their AUC’s for LDA and QDA?

The ROC curve shows the ability of a classification model to distinguish between classes at different thresholds. The two axis represent Sensitivity or true positive rate against the specificity or false positive rate. As the threshold level changes the balance between these two changes and is shown by the curve. AUC is the area under the curve which summarizes the overall performance of the classifier by providing a value between 0 and 1. 0.5 would be the typical value of a classifier that just randomly picks classes to assign to. 1 would be a perfect classifier and 0 would be a bad classifier.

If you were to create an ROC curve for two synthetically generated data sets from the same distribution, you would likely get 2 curves that are very similar but may or may not be identical. This is because both datasets may have some sampling variability which leads to differences in the points, and that the decision boundaries that are created by looking at the training data may be slightly different because of randomness in data sampling.

I suspect that the code provided in the lecture notes wouldn’t be sufficient to generate ROC curves for 3 or more classes. When there are more than 3 classes the thresholds become more complicated and I’m not sure how you would display that with a ROC curve.

6.5) Describe the key similarities and differences, respectively, between LDA and logistic regression. Provide a situation where discriminant analysis can still be sensibly applied but logistic regression is not well-defined.

Similarities: - LDA and Logistic Regression are both supervised learning techniques for classification tasks. - Both use a linear decision boundary. - Both methods model the probability of a data point belonging to a class

Differences: - LDA assumes the features are normally distributed, Logistic Regression does not care about the distribution of the data. - LDA estimates the class conditional probabilities and uses Bayes rule to compute the posterior probability, logistic regression models the probability of a class with the sigmoid logistic function.

A situation where LDA would work but logistic regression may not, is in a situation where the data set is high dimensional but the number of observations is low. This could be the case in research of a rare genetic disease where there are many gene expressions but not that many people have the disease with the “correct” gene expressions to study. In this case LDA can be applied because it just estimates the means and covariance matrices of the classes (has disease vs doesn’t have disease) even with a small sample set, it can still work. But the logistic regression model may struggle to estimate the coefficients for its logistic function. It won’t be able to find a stable solution because it will over fit and struggle with the multidisciplinary of the data.

(8.1) What is the main cause of the message “Warning in lda.default(x, grouping, …): variables are collinear”? What is the main cause of the message “Error in qda.default(x, grouping, …) : some group is too small for ‘qda’”?

  • The variables are colinear message is shown when one or more variable in the data set form linear combinations of others, this results in a covariance matrix that in not invertible which the LDA calculation relies on to calculate the discriminant function. This introduces instability to the calculations where it becomes overly sensitive to small adjustments

  • The too small for qda message means that the groups in the predicted (response) variable has too few observations. Because QDA relies on estimating separate covariance matrices for each group there need to be a sufficient number of observations relative to the number of predictors to generate accurate estimates. If the groups are too small the estimations can fail or become unstable possibly resulting in inaccuracy

(8.2) Provide details on the list that predict{MASS} returns.

  • For the predict.lda() method, the return of the method is a list with three components: Class, posterior, and x. The class specifies the predicted class as a factor, posterior gives the posterior probabilities for the classes, and x gives the scores of the test cases.
  • For predict.qda() the list only contains the posterior and class components which are the same as lda. The x component is omitted.
